# FrostyGoodness — Premium Frozen Fruits

A premium, responsive React/Vite landing page inspired by the supplied FrostyGoodness poster.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build for production

```bash
npm run build
npm run preview
```

## Notes
- The supplied poster is included as `public/frostygoodness-poster.png` and used as the hero/feature visual.
- Product photography currently uses remote Unsplash image URLs. Replace these with your final product photography before production.
- Basket interactions and the contact form are front-end demo interactions; connect them to your backend/payment/CRM when ready.
